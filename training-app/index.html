Cross-device sync

Sync your schedule, workouts, routines and library across this computer and your phone using a free Firebase database. Enter the same Database URL on every device.

  1. Go to console.firebase.google.com and create a project (any name).
  2. In the left menu open Build → Realtime Database, click Create Database, pick a location, and start in test mode.
  3. At the top of the database page, copy the URL that looks like https://your-project-default-rtdb.firebaseio.com.
  4. Paste it below and click Connect. Then do the same on your phone.

Note: while connected, the most recent edit on any device wins. For better privacy you can later restrict the database with Firebase rules — ask anytime.
