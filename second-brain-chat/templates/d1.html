How the score works. 0 = wide-open guard room, 100 = locked down — ranked for 2027-28, the season Alex would arrive. Only guards who'll still be there can block him, so departing seniors count as vacated minutes, not competition. Score = returning quality (0-55, top returner weighted double) + roster crowding (0-25) − a vacancy credit (up to 30) for minutes walking out.
